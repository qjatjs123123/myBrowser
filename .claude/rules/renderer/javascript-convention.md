# JS/TS 함수 규칙

- 함수 15줄 이내, 단일 책임 — 일반 함수·훅·도구·핸들러 기준. React 컴포넌트는 「책임 한 문장」 기준.
- 인자 3개 초과면 객체로. early return 으로 중첩 축소. 순수 함수 지향 — 부수효과는 호출부로.
- `any` 금지, `unknown` + 좁히기. `as` 캐스팅은 zod 결과·외부 라이브러리 경계에서만.
- 비동기는 `async/await`. `Promise` 를 버리지 않는다(`void fn()` 명시). 에러는 **경계**(IPC 핸들러·도구 루프·앱 진입)에서만 잡고 안쪽은 전파.

## 유틸 위치
- 프로세스 무관 순수 함수(문자열 정규화, 패턴 매칭) → `src/shared/utils/{name}.ts`.
- renderer 전용 순수 함수 → `src/renderer/utils/`. main 전용 → 그 모듈 폴더 안 `{name}.ts`.
- 한 파일에서만 쓰는 헬퍼는 그 파일 하단의 모듈 함수.
- 상수는 `{name}Constants.ts`.

## 주석
- 공용 코드(shared, hooks, utils, lib, 도구)는 **JSDoc 한 줄 이상 필수** — 무엇을 위한 것인지. "왜"를 쓰고 "무엇"은 반복하지 않는다.
- 도구의 `description`(모델이 읽는 문장)과 코드 주석을 구분한다 — 전자는 스키마 파일에, 후자는 구현에.
- `// TODO: {무엇을 하면 지울 수 있는지}`.
