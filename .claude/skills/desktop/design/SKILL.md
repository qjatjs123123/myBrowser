# 화면 디자인 — myBrowser 기준

이 앱은 **브라우저**다. 사용자의 주 관심은 탭 안의 웹페이지이고, 우리가 그리는 UI(상단 크롬·사이드바)는 그것을 방해하지 않아야 한다.

## 0. 우선순위 (충돌 시 위가 이긴다)
1. **앱 디자인 토큰** — `src/renderer/styles/globals.css` 의 shadcn 변수(`--background`, `--primary`, `--muted` …). 색 하드코딩 금지.
2. **shadcn/ui 부품** — `@/components/ui/*`. 없는 부품은 `pnpm dlx shadcn@latest add <부품>`.
3. 이 문서의 원칙.

## 1. 레이아웃
```
┌─────────────────────────────────────────────────────────────────┐
│ ● ● ● [탭][탭][+]                 (빈 곳 = 창 드래그)              │
│ ◀ ▶ ⟳  [주소창                                    ]  [✻ 에이전트] │ ← 패널 열기/닫기
├──────────────────────────────────────────────┬──────────────────┤
│                                              │ 에이전트 [완료] + ✕│ ← ✕ 닫기
│                                              │    ( 오늘 7시 2명… ) │ ← 할 일 말풍선
│                                              │ ✻ 3단계 ˅          │ ← 접기 헤더
│          WebContentsView (웹페이지)            │  │ ✓ 페이지 읽기     │
│                                              │  │ ⧗ ‘예약 확정’ 클릭 │
│                                              │ ● 결과 문단         │
│                                              │ ⊙ 완료  ⧉          │
│                                              │ ┌ 승인 필요 ──────┐ │
│                                              │ │  1. 직접 누를게요 │ │
│                                              │ │  2. 에이전트가…  │ │
│                                              │ │› 3. 거부        │ │ ← 기본 강조
│                                              │ └────────────────┘ │
│                                              │ ╭ 할 일을 입력…   ╮ │
│                                              │ ╰ Enter 실행   (↑)╯ │
└──────────────────────────────────────────────┴──────────────────┘
```
- **프레임 없는 창 (mac Chrome형, spec 010)**: OS 제목 표시줄 없음. 맨 윗줄(36px, `bg-muted`) = 신호등 + 탭 + [+], 창 전체 폭. 빈 곳은 `[-webkit-app-region:drag]`, 탭·버튼은 `no-drag`(빠지면 클릭이 먹히지 않는다).
- **에이전트 패널 열기·닫기 (Edge형, spec 011)**: 탭 줄·툴바는 창 전체 폭, 툴바 오른쪽 끝 [✻ 에이전트] 알약 버튼(`aria-pressed` = 패널 보임). 그 아래 [탭 콘텐츠 | 패널]. 패널 헤더(44px, 드래그 아님)의 ✕ 로 닫는다. 닫아도 언마운트하지 않고 `hidden` — run·대화·입력 유지. **승인·질문이 오면 닫혀 있어도 자동으로 보이고**(렌더 중 계산 — 거부 포커스 유지), 사용자가 다시 닫으면 버튼에 `--warning` 점·`aria-description="확인 필요"`. 열림 상태는 `localStorage` `mybrowser:layout`.
- **폭 조절·단축키 (spec 012)**: 패널 왼쪽 가장자리 손잡이(`role=separator`, 300~640px, ←/→ 16px)로 폭을 바꾸고 `mybrowser:layout.sidebarWidth` 에 기억. Ctrl+Shift+A(mac Cmd+Shift+A)로 [에이전트] 와 같은 토글.
- **실행 기록 (spec 012)**: 패널 헤더 [실행 기록](History) → 대화 자리에 최근 50개 목록 → 줄을 누르면 말풍선·에이전트 턴으로 읽기 전용 보기. 실행·승인 버튼 없음, 도구 입력값 원문 없음.
- 신호등: macOS 는 네이티브(`hiddenInset`, 72px 자리만 비움), Linux·Windows 는 `chrome/WindowControls` 가 닫기·최소화·최대화 원(12px, `--traffic-*` 토큰)을 그리고 `window:*` IPC 로 동작. 묶음 hover 시 ×·−·+.
- 상단 크롬 높이는 탭 줄 36px + 주소창 줄 40px. 사이드바는 오른쪽 360px, [에이전트] 버튼으로 토글.
- 탭 영역의 크기는 main 이 `WebContentsView.setBounds` 로 맞춘다 — renderer 는 자기 레이아웃만 그리고 크기 변화를 IPC 로 알린다.

## 2. 크롬(상단바) 원칙
- **중립·저대비**: 배경 `bg-background`, 경계 `border-border`, 아이콘 `text-muted-foreground`. 강조색은 쓰지 않는다 (페이지 콘텐츠와 경쟁 금지).
- 주소창은 `Input` 기반, 포커스 시만 `ring`. 로딩은 주소창 왼쪽 작은 스피너, 진행 막대 금지.
- 탭은 활성만 `bg-background`, 나머지 `bg-muted`. 닫기 버튼은 hover 시 노출. 파비콘 16px.
- 키보드: Ctrl+T/W/L/R/Tab·Alt+←/→ 는 main 이 메인 창·탭 webContents 의 `before-input-event` 로 처리한다 (`src/main/tabs/shortcuts.ts`, 탭 View 에 포커스가 있어도 동작). 메뉴 accelerator 는 등록하지 않고(메뉴 막대도 숨김, 편집 메뉴만), renderer 는 키를 등록하지 않는다 — 포커스가 필요하면 main 이 `shortcut:pressed` 이벤트로 알린다. (spec 002)

## 3. 사이드바 원칙 — 상태가 먼저 보인다 (대화형, spec 009)
- **대화형**: 할 일 = 오른쪽 `bg-muted rounded-2xl` 말풍선, 에이전트 = `✻ N단계 ˅` 접기 헤더(타임라인) → ● 결과 문단 → 상태 문구 + 복사 줄. 세션 안에서 위→아래로 쌓이고(renderer 메모리, 재시작 시 사라짐) 헤더의 [새 대화]로 비운다. **지난 턴만 접고 현재 턴은 끝나도 펼친다.**
- 강조색 `--brand`(테라코타)는 사이드바의 전송 버튼·✻ 아이콘·선택 목록 `›` 에만. 크롬에는 쓰지 않는다.
- 맨 위 헤더 줄: 제목 `에이전트` + **현재 상태 배지** 하나: `대기` / `실행 중` / `승인 필요` / `질문` / `완료` / `실패`. `승인 필요`·`질문` 은 `bg-primary` 로 유일하게 강조.
- **단계 타임라인**: 한 줄 = 도구 호출 하나. 아이콘(도구 종류) + 사람 말로 된 요약("예약 페이지 열기", "날짜 11월 7일 선택") + 결과 상태. 원문 JSON 은 접힌 상세에.
- 에이전트의 **생각**(thinking 요약)은 작은 회색 글씨로 접어서. 기본 접힘.
- 스크린샷 썸네일은 타임라인 옆 64px, 클릭하면 확대.
- 작업 입력은 하단 둥근 카드(`rounded-2xl`) 자동 높이 `Textarea` + 오른쪽 아래 원형 실행 버튼(↑). **Enter = 실행**, Shift+Enter 줄바꿈, **IME 조합 중 Enter 무시**(한글). 시작되면 입력을 비운다. 실행 중엔 입력을 잠그고 같은 자리에 원형 **중지** 버튼.

## 4. 승인·질문 카드 — 놓치면 안 되는 결정
- 탭 View 가 renderer 위에 그려지므로 모달이 아니라 대화 끝(입력창 위)의 `rounded-xl` 카드(`role="alertdialog"`/`"dialog"`). 제목 "승인 필요" / 질문 문장, 테두리·아이콘만 `--warning`. 본문은 **에이전트가 하려는 행동 + 대상(버튼 문구·URL) + 이유** 를 그대로 보여준다.
- 선택은 Claude Code 식 **번호 선택 목록**(`sidebar/ChoiceList`): `› 1. 라벨`, ↑↓ 이동(순환)·숫자키 바로 선택·Enter/Space/클릭 선택. 가드 승인은 [직접 누를게요]/[에이전트가 누르기]/[거부], 모델 승인은 [승인]/[거부].
- **승인 카드의 기본 강조·포커스는 거부** — 열자마자 Enter 는 거부다. 승인은 ↑↓·숫자키·클릭으로만. Enter·Space 는 keydown 에서 preventDefault 해 1회만 전송.
- 질문 카드는 선택지 목록(첫 선택지 포커스) + 자유 입력(선택지가 없으면 여기에 포커스).
- 모달이 떠 있는 동안 타임라인은 `승인 대기` 로 표시하고, 탭 위에는 반투명 테두리(에이전트가 가리키는 요소를 하이라이트)를 둔다.

## 5. 공통
- 문구는 한국어, 짧게. 버튼은 동사("승인", "거부", "중단", "실행").
- 로딩/에러/빈 상태를 모두 처리한다 — 타임라인이 비었으면 "할 일을 입력하면 여기에 진행 상황이 표시됩니다".
- 아이콘은 lucide-react 만. 클릭 영역 최소 32×32(데스크톱 앱 기준).
- 다크 모드는 OS 설정을 따른다(`prefers-color-scheme`), 토큰으로만 대응. e2e 로 다크를 볼 때는 Playwright 기본 light 에뮬레이션을 먼저 푼다(`emulateMedia({ colorScheme: null })` — TROUBLESHOOTING).
- 애니메이션은 150ms 이내, 상태 전환(배지·타임라인 추가)에만.
